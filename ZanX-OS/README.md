# ZanX OS

ZanX OS is a retro-styled, modern Linux live distribution project inspired by Linux desktops from roughly 2000–2005.

**Design target:** black/dark gray surfaces, dark red accents, square controls, pixel-ish icons, classic Openbox + Tint2 desktop, terminal-first tooling, and no glass/blur/Material styling.

## What is included

- Debian 13 (Trixie) base, amd64
- Openbox desktop
- Tint2 classic panel
- PCManFM presented to users as **Explorer**
- Mousepad presented as **Notepad**
- File Roller + 7-Zip presented as **WinRAR**
- Firefox ESR
- XTerm
- LightDM login manager with ZanX branding
- Custom GTK CSS, Openbox theme, panel configuration and wallpapers
- Classic 32×32 pixel-style ZanX icons
- Exact ZanX ASCII-art source and generated boot/login artwork
- Build scripts for a reproducible ISO

## Build

### Native Debian/Ubuntu build host

Install the build dependency:

```bash
sudo apt update
sudo apt install live-build debootstrap xorriso squashfs-tools grub-pc-bin grub-efi-amd64-bin mtools dosfstools
```

Then:

```bash
cd ZanX-OS
chmod +x build-zanx.sh
sudo ./build-zanx.sh
```

The ISO is written to `dist/`.

### Docker/Podman

A container recipe is provided in `docker/Dockerfile`:

```bash
docker build -t zanx-builder -f docker/Dockerfile .
docker run --rm --privileged -v "$PWD/dist:/workspace/dist" zanx-builder
```

A privileged container is used because live-build needs loop devices and image-building tools.

## Default user

The live system is configured for the live-config username:

`zanx`

The desktop is intended to auto-login through LightDM when booted as a live image.

## Application aliases

| ZanX name | Linux implementation |
|---|---|
| Explorer | PCManFM |
| Notepad | Mousepad |
| WinRAR | File Roller + 7-Zip |
| Firefox | Firefox ESR |

The aliases are intentional: the visual identity uses the requested names while the underlying software remains native Linux software.

## Design notes

The project deliberately avoids modern rounded cards, blur, gradients, Material-like controls and neon/cyberpunk styling. The desktop is built from Openbox, Tint2 and GTK settings so the result feels like a small Linux distribution from the early 2000s rather than a modern desktop with a red wallpaper.

## Important

This repository is a **complete buildable distro source tree**, not a claim that a large binary ISO is embedded in the ZIP. The ISO is generated by `build-zanx.sh` from Debian repositories on the build machine.

## GitHub Actions build (Windows-friendly)

The repository includes `.github/workflows/build-zanx.yml`. This lets you build the bootable ISO on GitHub's Ubuntu runner without installing Linux, WSL, Docker or VirtualBox on Windows.

See `GITHUB-BUILD.md` for the exact steps: upload the repository, open **Actions → Build ZanX OS → Run workflow**, then download the generated ISO from the workflow artifact.
